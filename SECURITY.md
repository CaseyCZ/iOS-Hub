# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in iOS Hub, please report it privately through GitHub's **Private vulnerability reporting** feature instead of opening a public issue.

Please include, when possible:

- a clear description of the issue,
- steps to reproduce it,
- the affected page, file, or feature,
- the expected and actual behavior,
- any proof-of-concept details that help verify the issue.

Please avoid publicly disclosing security-sensitive details until the issue has been reviewed and, when necessary, fixed.

## Supported code

Security fixes are applied to the current `main` branch and the currently deployed iOS Hub website.

## Non-security bugs

For normal bugs, UI problems, broken links, source issues, or feature requests, please use the public GitHub Issues tracker.
