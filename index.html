How Mix works
  • Uses only pre-approved public source URLs.
  • Automation checks JSON validity and source availability.
  • Apps are deduplicated by bundleIdentifier.
  • On conflict the newer entry wins when a reliable release date is available.
  • PAL and large community sources are added directly, not through Mix.
